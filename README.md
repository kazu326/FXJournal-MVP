# FXJournal-MVP

FXトレード学習・日誌管理アプリケーション。トレード前後のGate判定記録、講義ノート視聴、進捗管理機能を提供します。

---

## プロジェクトの背景

FXトレードは高いリスクを伴うにもかかわらず、多くの個人トレーダーが十分な準備や理解がないまま参入し、短期間で市場から退場しています。

この背景には構造的な課題があります。
FX業者は企業として利益を最大化するため、ユーザーの参入障壁（UX）を意図的に低く設計しています。一方で、規制当局は心理的バイアスや行動経済学的な問題を完全に抑制することが難しく、「プリンシプルベース（原則ベース）」の規制へと移行しています。

しかし現状では、この "自己管理責任" を支援する実践的なツールは十分に存在していません。

本プロジェクトはこの課題に対し、  
**「勝つため」ではなく「退場しないため」のトレード支援** を目的として開発されています。

特に以下に焦点を当てています：

- トレード前の意思決定プロセスの標準化
- 心理的バイアス（過信・衝動・損失回避など）の可視化
- 継続的な振り返りと行動改善の仕組み化

その実現手段として、**ゲーミフィケーションを取り入れた学習・トレード日誌システム** を設計しました。

ユーザーはトレード前に「4つのGate（取引回数・RR・リスク・ルール）」を通過する必要があり、これにより衝動的なエントリーを抑制し、再現性のある意思決定を促します。

本プロジェクトは個人開発としてスタートし、現在も Vercel 上で運用されながら継続的に改善されています。  
今後は OSS として公開し、より多くの開発者・トレーダーとともに進化させていくことを目指しています。

---

## プロジェクト概要

FXJournal-MVP は、FXトレード初心者〜中級者が「早期退場しないこと」にフォーカスして学習・記録・振り返りを行える、オープンソースのトレード日誌アプリケーションです。

### 技術スタック

| カテゴリ | 技術 |
|---------|------|
| フレームワーク | React 19 + TypeScript |
| ビルドツール | Vite (rolldown-vite) |
| スタイリング | TailwindCSS 4.x |
| ルーティング | React Router DOM 7.x |
| バックエンド | Supabase（認証、DB、Edge Functions） |
| ホスティング | Vercel |
| アイコン | Lucide React |
| 通知 | react-hot-toast |

### 主な機能

- 取引前の「4つのGate」判定（取引回数・RR・リスク・ルール）
- 取引ログの記録と振り返りビュー
- 講義動画の視聴ステータス管理
- 管理者用ダッシュボード（ユーザーの進捗確認・コーチング補助）
- モバイル利用を意識したレスポンシブ UI
- PWA対応（オフライン対応、ホーム画面追加）

本リポジトリは、行動経済学・トレード教育・コーチング現場での知見を反映した、**行動設計に強いトレードジャーナル OSS** を目指しています。

### Live Demo

- Production: https://fx-journal-mvp.vercel.app/

## OSS としての目標

FXJournal-MVP は、単なる 1 アプリではなく、以下のような OSS としての価値提供を目指します。

- 他の金融教育・投資教育プロダクトでも再利用可能なコンポーネント設計
- 「4つのGate」ロジックや評価指標を、他プロジェクトでも活用しやすい形でモジュール化
- 教育者・コーチ・コミュニティ運営者が、自分たちのルールセットに合わせて拡張できるアーキテクチャ

今後、Issue / Discussion を通じて

- 新しい Gate ロジックの提案
- 異なる市場（株式、暗号資産など）への拡張
- 分析ダッシュボード・レポート機能の追加

などを、コミュニティと共に進化させていきます。

## セットアップ

### 1. 依存関係のインストール

```bash
npm install
```

### 2. 環境変数の設定

`.env.local` ファイルをプロジェクトルートに作成し、以下を設定：

```env
VITE_SUPABASE_URL=your_supabase_url
VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
```

### 3. 開発サーバーの起動

```bash
npm run dev
```
