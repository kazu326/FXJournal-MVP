# FXJournal-MVP Roadmap

This is an informal roadmap of areas I plan to work on. Priorities may change based on user feedback and contributor input.

## Short term (0–3 months)

- Refine 4-Gate logic and make it configurable
- Improve trade log review UX (filters, tags, notes)
- Basic test coverage for core components
- Developer documentation for setup and deployment

## Mid term (3–6 months)

- Multi-market support (stocks, crypto) through configurable rule sets
- Export / import of journal data (CSV/JSON)
- API endpoints for integration with other tools
- More detailed analytics dashboards

## Long term (6+ months)

- Pluggable “behavior modules” for different coaching styles
- Multi-language support
- Integration patterns for other OSS education platforms
- Research / case studies on behavioral impact of the 4-Gate system
