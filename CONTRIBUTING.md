# Contributing to FXJournal-MVP

Thank you for your interest in contributing to FXJournal-MVP!

This project aims to provide an open-source, behavior-focused trading journal that helps retail traders avoid destructive trading patterns. Contributions that improve usability, clarity, and extensibility are especially welcome.

## How to get started

- Check the open Issues and Discussions for existing ideas.
- If you want to propose a new feature or behavior model (e.g. new Gate logic), please open an Issue first.
- For small fixes (typos, UI tweaks), feel free to open a Pull Request directly.

## Development setup

- Frontend: React 19 + TypeScript
- Backend / BaaS: Supabase
- Deployment: Vercel

Recommended steps:

1. Fork this repository.
2. Create a new branch from `main`.
3. Make your changes with clear, small commits.
4. Run the app locally and confirm that your changes work.
5. Open a Pull Request with:
   - A short description of what you changed
   - Screenshots or GIFs for UI changes (if applicable)
   - Notes on any migration or config changes

## Types of contributions

- Bug fixes
- UX / UI improvements
- New analysis or review views for trade logs
- New Gate logic and behavioral checks
- Documentation improvements (README, usage guides, etc.)

## Code style

Please keep the code simple and easy to reason about. If in doubt, prefer clarity over cleverness.

If you are using AI tools (such as Codex) while contributing, please double-check the output and ensure that:
- The code is secure and does not expose secrets
- The changes are consistent with the existing architecture and style
